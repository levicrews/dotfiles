# Update bibliography entry

Use this skill when the user asks to update, correct, refresh, verify, reconcile, or audit an existing work in the `crewsbib` bibliography. The repository root is the directory containing `crewsbib.bib` and `pdf/`. From that directory, the related Org-roam tree is `../org/roam/`, with reference notes normally under `../org/roam/refs/`.

Read [crewsbib-conventions.md](../bib-common/references/crewsbib-conventions.md) before editing. Treat the existing entry and comparable nearby records as the starting point, but replace stale or incorrect metadata with authoritative evidence.

Workflow:

1. Identify the exact existing record. Search by cite key, DOI, NBER number, title, and author names; do not update a merely similar work. If multiple records may represent the same work, inspect them together and explain the ambiguity before making a destructive merge or deletion.
2. Check specifically for a final published version or a newer release of the NBER working paper. Use authoritative sources in this order as appropriate: final journal or book publisher, DOI/Crossref, NBER, and author page. Verify the title, all authors/editors, publication status, year, journal or book details, volume/issue/pages, DOI, stable URL, abstract, JEL codes, and NBER number when relevant. If metadata or the PDF is gated, explicitly prompt the user to connect through university VPN or otherwise provide access; do not silently fall back to an inferior version or invent missing fields. Continue only after access is available or report the item as blocked.
3. Derive the target cite key from the verified record using the shared conventions. A newer publication or release year requires a new cite key with the new year; do not keep the old-year key merely to avoid renaming. Before changing a cite key, record the old-to-new mapping, check for collisions, and search all affected files. Use lowercase `a`, `b`, etc. only for unavoidable same-base-key collisions.
4. Make the smallest complete correction in `crewsbib.bib`. Update the entry type and fields when the verified publication supersedes an NBER working paper; preserve accurate local fields and remove or replace only metadata that is stale, unsupported, duplicated, or contradicted by evidence. Keep `keywords` limited to verified JEL codes. Do not invent an abstract, publication detail, file, or URL. If a requested correction cannot be verified, leave that field unchanged and say why.
5. For a new or replacement PDF, verify that it belongs to the same work. If the existing PDF contains highlights, comments, or other user annotations, preserve it by renaming it to `pdf/[new-citekey]_OldVersion.pdf` before saving the new unannotated/current PDF as `pdf/[new-citekey].pdf`. Always use the final/new cite key for both filenames, even when the old and new cite keys differ; do not leave the preserved file under the old cite key. Update the BibTeX `file` field(s) to match actual files, and never overwrite an annotated PDF silently. Preserve other distinct files such as appendices, slides, or comments unless they are demonstrably obsolete.
6. Synchronize Org-roam after determining the final cite key. Look in `../org/roam/refs/` for the corresponding reference file, normally `../org/roam/refs/[citekey].org`, using the old and new cite keys plus title/author metadata to identify it. If the cite key changed and `../org/roam/refs/[old-citekey].org` exists, rename it to `../org/roam/refs/[new-citekey].org` before editing it; always use the final/new cite key for the filename. Then update that Org file’s bibliographic metadata to match the verified record while preserving unrelated notes, links, and user prose. Finally, search `../org/roam/` recursively, including all subdirectories, for the old cite key and update references to the new cite key. Review each replacement so that ordinary prose or a different work is not changed accidentally. If no corresponding Org file exists, report that fact; do not create one unless the user asks.
7. Validate the result: the target record is unique, braces remain balanced, the entry type and core fields match the verified publication, the old-to-new cite-key mapping is applied consistently in `crewsbib.bib`, Org-roam metadata, and all recursive Org-roam references, keywords are JEL codes only, abstracts and publication details are sourced, and all linked files exist. Compare the diff with the prior entry and avoid unrelated reformatting.

Updating an entry authorizes edits to the bibliography, the corresponding Org-roam metadata and cite-key references, and replacement or addition of the requested local paper file. It does not authorize bypassing access controls or deleting annotated or distinct historical files. Prompt for VPN access when the authoritative publication record or PDF requires it.

## Final report

Report each updated cite key and, when applicable, the old-to-new mapping; list the fields changed, whether the record is now a published or working-paper version, PDF preservation/renaming actions, the corresponding Org-roam file updated (or not found), and the number or locations of recursive Org-roam references changed. Also list any requested records that were not found, ambiguous, unchanged because no reliable correction was available, or blocked pending VPN access.
